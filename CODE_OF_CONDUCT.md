# Code of Conduct

## Our Pledge

We are committed to making participation in this project a welcoming and respectful experience for everyone.

## Our Standards

Examples of positive behavior include:

- Being respectful and considerate.
- Welcoming different opinions and ideas.
- Giving constructive feedback.
- Focusing on what is best for the project.

Unacceptable behavior includes:

- Harassment or discrimination.
- Personal attacks.
- Trolling or insulting comments.
- Publishing private information without permission.

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards.

If you experience or witness unacceptable behavior, please report it to the project maintainers.

## Scope

This Code of Conduct applies to all project spaces and interactions related to this project.
