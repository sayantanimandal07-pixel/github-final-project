# Simple Interest Calculator

A simple Bash script that calculates simple interest based on principal amount, annual rate of interest, and time period.

## Formula

Simple Interest is calculated using:

SI = (P × R × T) / 100

Where:

- P = Principal Amount
- R = Rate of Interest
- T = Time in Years

## Requirements

- Linux/macOS terminal or Windows with WSL/Git Bash
- Bash
- bc calculator utility

## How to Run

Clone the repository:

git clone https://github.com/sayantanimandal07-pixel/github-final-project.git

Go into the project directory:

cd github-final-project

Give execution permission:

chmod +x simple-interest.sh

Run the program:

./simple-interest.sh

## Example

Enter Principal Amount: 10000
Enter Rate of Interest: 5
Enter Time (in years): 2

Simple Interest = 1000.00
